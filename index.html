歌單轉入

雙擊 開始.bat（Windows）或 開始.command（Mac）就會自動打開。可從網址抓歌、貼 CSV／試算表，再搜 YouTube 伴奏轉成 Elitesand 歌單。

你現在是直接打開網頁檔，網址抓歌與 YouTube 搜尋會失敗。請改雙擊同資料夾的 開始.bat（Windows）或 開始.command（Mac），它會自動啟動並打開正確頁面。CSV／試算表轉成 Elitesand json 仍可在這裡做。

從網址抓歌

貼上公開歌單網址，例如 https://streamersonglist.com/t/名稱/songs

從 CSV／試算表轉入

上傳 CSV，或從 Excel／Google 試算表複製後貼上。需要有歌名欄；歌手欄建議也有。

標題 歌手 屬性 YouTube 上次播放 播放次數

先按「搜尋 YouTube」幫目前畫面上的歌找伴奏網址（搜尋會帶「伴奏」），再下載 Elitesand 歌單。Elitesand Pro 匯入不會開檔案視窗，只列出 %APPDATA%\Elitesand Pro\data\playlist-exports（一般是 C:\Users\你的名字\AppData\Roaming\Elitesand Pro\data\playlist-exports）。資料夾沒有就先建，放進 json 後在程式裡匯入。搜尋需要本機已安裝 yt-dlp（pip install yt-dlp）。結果仍可能對到錯版本，匯入前請看一下。

請用「開始」啟動，不要只雙擊 index.html。網址來源只讀 streamersonglist.com；表格在瀏覽器解析；YouTube 搜尋走本機 yt-dlp 並加「伴奏」。版本 v0.4.2。
